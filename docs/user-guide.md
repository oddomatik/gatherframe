# Studio workflow

1. Create a project, configure access, sharing preview, downloads and print products.
2. Export finished JPEGs from Lightroom. Use matching base filenames for full-resolution, social and optional RAW versions.
3. Upload versions into the project; matching versions keep one photo identity. Review conflicts before replacement.
4. Organize into collections; one photo can appear in several families without duplicating the original.
   Use project-defined hierarchical tags for days, activities or groups.
5. Inspect guest access using actual guest links separately from the privileged owner preview, then share.
6. Review orders and requests, approve the exact print master, record manual payments and production progress.
7. Inspect Visibility for activity after tracking began. It reports actions, not a census of families or guaranteed device saves.
